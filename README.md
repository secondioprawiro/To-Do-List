# 📝 Aplikasi To-Do List Sederhana

Aplikasi ini dibuat untuk latihan/pembelajaran mengenai pembuatan aplikasi berbasis web dari awal

Aplikasi manajemen tugas berbasis web sederhana yang dibangun menggunakan **HTML, CSS, JavaScript, dan PHP**. Aplikasi ini memungkinkan pengguna untuk membuat, membaca, memperbarui status, dan menghapus tugas (CRUD) dengan antarmuka yang bersih dan responsif.
